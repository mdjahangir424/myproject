# Md Jahangir Alam | Portfolio Website

Portfolio site for Md Jahangir Alam, Flutter Developer and AI Automation Specialist.

A single static page (`index.html`) with no build step. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository **Settings** and go to **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.

The site will be available at `https://mdjahangir424.github.io/myproject/` after a minute or two.
